Historial del ciclo

Los registros de hoy se excluyen del resumen mientras el día esté en curso. Edita una fecha seleccionando “Abrir”. La producción en sábados no afecta el promedio.

Feriados, vacaciones y ausencias

Los sábados y domingos se excluyen automáticamente. Puedes agregar feriados, vacaciones y otras ausencias no computables. La descarga automática de feriados de Chile depende de tener conexión; revisa la lista y ajústala según las reglas de tu trabajo.

Exclusiones en el ciclo

Las recetas de un día excluido suman al total pagable, pero no al promedio, salvo que tu empresa aplique otra regla.

Configuración de tarifas

Los montos son editables. Los valores de tu empresa aún no están completos (en particular, debajo de 201 recetas).

Reglas del cálculo

El pago de las recetas de pedidos siempre se incluye en el bono total; esta opción modifica únicamente el promedio que define el tramo. Se paga un adicional por cada fecha trabajada que sea sábado o feriado (aunque coincidan, se paga una sola vez).

⏱ Mis tiempos de elaboración

Indica cuánto tardas, en promedio, en una receta de cada grupo (minutos). Son tiempos personales de este dispositivo; cada persona puede configurar los suyos. No modifican las reglas del bono.

Copias de seguridad

Para conservar tu historial: descarga un JSON antes de cambiar de archivo, abrir otro acceso directo o importar. El acceso desde Mis archivos puede usar un almacenamiento diferente. Importar aquí combina fechas nuevas y conserva las existentes salvo que confirmes reemplazarlas.

El archivo HTML no contiene necesariamente los registros de la versión anterior: estos normalmente se guardan en el almacenamiento del navegador. Si ya tienes un respaldo JSON de V1, impórtalo aquí para recuperar los registros. La V2.6 intenta leer datos anteriores del mismo origen, cuando Android lo permite, pero no debes confiar en la migración automática.

Para recuperar tus datos: selecciona «Subir respaldo JSON», elige el archivo en Descargas y revisa el mensaje que indicará las fechas incorporadas. Si hay fechas diferentes, se te preguntará cuáles conservar. Después comprueba el Historial. No borres el archivo JSON original.

PDF: al tocar “Guardar informe como PDF” se abre la impresión del navegador. En Android elige Guardar como PDF como destino. El PDF es para consultar o imprimir; el JSON es el respaldo que permite restaurar y seguir editando tus registros.
